# omatype

A typing speed test built with Qt Quick.

![omatype](screenshots/screenshot-1.png)
![omatype](screenshots/screenshot-2.png)

## Build

```sh
./bin/build
./build/omatype
```

## Test

```sh
./bin/test
```

## Install

```sh
./bin/install
```

Requires Qt 6 (`qt6-base`, `qt6-declarative`).

Inspired by [Monkeytype](https://monkeytype.com) and OmaWrite.
